# UC-01 — Visualizar camadas de segurança e infraestrutura

**Produto:** Luminar 

**Objetivo:** Permitir que a usuária personalize a visualização do mapa, ativando camadas específicas que exibam elementos de segurança e infraestrutura urbana para auxiliar na tomada de decisão sobre seu trajeto

## Atores

- **Usuária** 
- **Sistema (Mapbox API)** 

## Regras de negócio aplicadas

### RN-01 — Disponibilidade de Camadas
- As camadas disponíveis para ativação devem incluir, no mínimo:
  - **Segurança:** Pontos Violeta (refúgio), delegacias e patrulhamento recente[cite: 55, 166].
  - **Infraestrutura:** Iluminação pública e comércios abertos.

### RN-02 — Dinamismo Temporal
- A visualização das camadas de "Comércio Aberto" e "Iluminação" deve ser filtrada automaticamente com base no horário local do dispositivo ou no horário simulado pela usuária.

### RN-03 — Hierarquia Visual (Z-Index)
- Os ícones de "Pontos Violeta" (ícones roxos) devem ter prioridade visual sobre outros marcadores de infraestrutura para garantir rápida identificação em caso de emergência.

### RN-04 — Persistência de Filtros
- As camadas selecionadas devem permanecer ativas durante a navegação de uma rota, a menos que a usuária as desative manualmente.

## Caso de uso: UC-01

### Pré-condições

- O aplicativo possui acesso à internet para carregar os dados do Mapbox.
- O GPS do dispositivo está ativo para centralizar o mapa na posição inicial.

### Gatilho

- Usuária aciona o botão de **“Filtros de Estado da Rua”** ou **"Camadas"** na tela principal do mapa.

### Fluxo principal (sucesso)

1. Sistema apresenta o mapa base renderizado via Mapbox.
2. Usuária aciona a ferramenta de filtros/camadas.
3. Sistema exibe as opções de camadas ativáveis: **Iluminação**, **Comércio Aberto**, **Patrulhamento** e **Pontos Violeta**.
4. Usuária seleciona uma ou mais camadas desejadas.
5. Sistema consulta o banco de dados (PostGIS) para recuperar as coordenadas dos elementos das camadas selecionadas.
6. Sistema renderiza os ícones de referência e estiliza as vias (verde, amarelo, vermelho) conforme o índice de segurança atual.
7. Sistema garante que os "Pontos Violeta" sejam exibidos com ícones roxos distintos.
8. Usuária visualiza o mapa atualizado e pode interagir com os ícones para ver detalhes.

### Pós-condições

- O mapa exibe visualmente os dados de segurança e infraestrutura solicitados.
- A usuária pode iniciar uma rota segura baseada nessas informações.

## Cenários de validação

### CT-01 — Ativar camada de Pontos de Refúgio (Pontos Violeta)
**Dado** que o mapa está visível  
**Quando** a usuária ativa a camada "Pontos Violeta"  
**Então** o sistema deve exibir ícones roxos em locais como farmácias, cafés e delegacias cadastrados.

### CT-02 — Alternar visualização por horário (Mapa Dinâmico)
**Dado** uma rua com comércio que fecha às 20h  
**Quando** a usuária altera o horário de visualização para 22h  
**Então** o sistema deve remover os ícones de "Comércio Aberto" dessa via e atualizar sua cor para Amarelo ou Vermelho (risco elevado).

### CT-03 — Visualizar áreas de iluminação precária
**Dado** que existem relatos de "luz quebrada" em uma via  
**Quando** a usuária ativa o filtro de "Áreas de Iluminação Precária"  
**Então** o sistema deve destacar visualmente as ruas com baixo índice de iluminação conforme os relatos colaborativos.

### CT-04 — Bloquear visualização sem conexão
**Dado** que o dispositivo está sem internet  
**Quando** a usuária tenta alterar as camadas  
**Então** o sistema deve informar que a atualização do mapa não é possível offline.

### CT-05 — Interação com Ponto de Refúgio
**Dado** um Ponto Violeta visível no mapa  
**Quando** a usuária clica no ícone roxo  
**Então** o sistema deve exibir informações do local e o botão para "Navegação de Emergência".

# UC-04 — Navegação e Zoom no Mapa

**Produto:** Luminar  
**Objetivo:** Permitir que a usuária explore diferentes áreas geográficas, ajuste o nível de detalhe visual e controle a perspectiva do mapa para planejar trajetos ou localizar pontos de referência.

## Atores

- **Usuária**
- **Sistema (Mapbox API / Renderizador Gráfico)**

## Regras de Negócio Aplicadas

### RN-01 — Agrupamento de Ícones (Clustering)
- Para evitar a poluição visual, o sistema deve agrupar ícones de infraestrutura (como postes de luz) em "clusters" numéricos quando o nível de zoom for baixo (visão macro). Os ícones individuais devem expandir-se automaticamente ao aumentar o zoom (visão micro).

### RN-02 — Limite de Zoom por Segurança
- O sistema deve restringir o nível máximo de zoom para garantir que a precisão dos dados de segurança não seja interpretada erroneamente fora do contexto da via.

### /// RN-03 — Renderização de Camadas por Nível de Detalhe
- Elementos detalhados de infraestrutura (como nomes de pequenos comércios ou estado individual de lâmpadas) só devem ser renderizados a partir de um nível de zoom específico para otimizar o desempenho do dispositivo.

### RN-04 — Orientação do Mapa
- O mapa deve permitir a rotação livre (gesto de dois dedos), mas deve oferecer um botão de "Reset de Norte" para reorientar rapidamente a visão da usuária.

## Caso de Uso: UC-04

### Pré-condições

- O mapa base está carregado e visível na tela principal.
- O dispositivo suporta gestos multi-toque ou possui controles de navegação ativos.

### Gatilho

- A usuária realiza gestos de deslizar, pinça (pinch) ou rotação na interface do mapa.

### Fluxo Principal (Sucesso)

1. O sistema detecta a entrada tátil (pan, zoom ou rotação).
2. O **Mapbox SDK** recalcula as coordenadas da "câmera" do mapa em tempo real.
3. O sistema ajusta a exibição das camadas de segurança conforme o nível de zoom:
    - **Zoom Baixo:** Exibe manchas de calor (heatmaps) de iluminação/segurança por bairro.
    - **Zoom Alto:** Exibe ícones individuais de Pontos Violeta e postes de luz.
4. O sistema mantém o marcador de localização da usuária (GPS) atualizado conforme a câmera se move (se a opção "seguir" não estiver travada).
5. A usuária visualiza os detalhes da área desejada com fluidez de movimento.

### Pós-condições

- A visualização do mapa reflete a nova área ou perspectiva escolhida pela usuária.

## Cenários de Validação

### CT-01 — Exploração por Deslizamento (Pan)
**Dado** que a usuária está visualizando sua localização atual  
**Quando** ela desliza o dedo para a direita  
**Então** o sistema deve mover o mapa suavemente para exibir as ruas adjacentes à esquerda.

### CT-02 — Zoom In para Detalhes de Segurança
**Dado** que o mapa exibe um "cluster" com o número "5" (indicando 5 pontos de refúgio)  
**Quando** a usuária realiza o gesto de pinça para aumentar o zoom  
**Então** o cluster deve se desfazer, revelando os 5 ícones roxos (Pontos Violeta) em suas localizações exatas.

### CT-03 — Rotação do Mapa
**Dado** que a usuária deseja alinhar o mapa com a direção da rua em que está caminhando  
**Quando** ela rotaciona o mapa com dois dedos  
**Então** a bússola do sistema deve indicar a nova orientação do Norte.

###  /// CT-04 — Perspectiva 3D (Tilt)
**Dado** que a usuária quer ver a volumetria dos prédios (para identificar pontos de referência visuais)  
**Quando** ela desliza dois dedos verticalmente para cima  
**Então** o sistema deve inclinar o mapa para uma visão 3D, facilitando a identificação de fachadas de comércios abertos.

### CT-05 — Reset de Visualização
**Dado** que o mapa está rotacionado e com zoom em uma área distante  
**Quando** a usuária pressiona o botão de "Centralizar Localização"  
**Então** o sistema deve realizar uma transição suave (animação) de volta para a posição GPS da usuária com o zoom padrão de navegação.

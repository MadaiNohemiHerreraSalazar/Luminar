UC-01

Produto: Luminar

Objetivo:
Renderizar no mapa a classificação de segurança de cada segmento de via em tempo real, utilizando cores para orientar a tomada de decisão da usuária antes e durante o deslocamento.

Atores
Usuária (Visualiza os dados)
Sistema (API Luminar / Engine de Processamento Geográfico)
PostGIS (Banco de dados com inteligência espacial)

Regras de Negócio Aplicadas
RN-06 — Composição do Score Dinâmico
O índice de segurança de uma rua é calculado através de uma média ponderada ($S$):
Peso 40% (Infraestrutura): Iluminação reportada e presença de Pontos Violeta.
Peso 40% (Relatos Recentes): Dados do UC-09 e RF-05 (Relato Rápido) dos últimos 7 dias.
Peso 20% (Fator Temporal): Ajuste automático conforme o horário (ex: ruas comerciais perdem score após o fechamento das lojas).

RN-07 — Legenda Semafórica de Risco
A visualização deve seguir estritamente o padrão de cores:
Verde ($Score \geq 4$): Via recomendada, alta iluminação e movimento.
Amarelo ($2.5 \leq Score < 4$): Via de atenção, iluminação parcial ou poucos relatos.
Vermelho ($Score < 2.5$): Via de risco, histórico de incidentes ou breu total.

RN-08 — Recálculo por Bounding Box
Para garantir a performance, o sistema deve processar o score apenas dos segmentos de via visíveis na tela da usuária (área de zoom atual).

UC-02

Pré-condições

O mapa base (Mapbox) está carregado corretamente (RF-01).
A usuária possui conexão de dados para baixar os tiles de segurança.

Gatilho

A usuária abre o app, movimenta o mapa ou aplica um filtro de "Estado da Rua" (RF-04).

Fluxo Principal (Sucesso)

O sistema identifica as coordenadas da área visível no smartphone da usuária.
O sistema solicita ao servidor o Índice de Segurança para aqueles segmentos de rua específicos.
O servidor processa a RN-06, cruzando relatos recentes com dados de infraestrutura.
O sistema sobrepõe ao mapa base uma camada de polilinhas coloridas (Verde, Amarelo ou Vermelho) sobre as ruas.
O sistema exibe ícones flutuantes em trechos específicos onde o score sofreu queda brusca (ex: ícone de lâmpada apagada).
A usuária visualiza as opções de caminho e identifica as "Zonas Verdes".

Pós-condições

O mapa exibe a realidade atualizada da segurança urbana de Cascavel.
O Smart Routing (RF-02) utiliza estes mesmos dados para traçar a rota.

Cenários de Validação

CT-06 — Atualização por Relato em Tempo Real
Dado que uma rua está sendo exibida como "Verde" (Segura).
Quando uma usuária envia um "Relato Rápido" (RF-05) de "Assédio" ou "Grupos Suspeitos".
Então o sistema deve rebaixar o índice da via para "Vermelho" imediatamente para todas as outras usuárias na região.

CT-07 — Transição Dia/Noite (Mapa Preditivo)
Dado que a usuária utiliza o simulador de horário (RF-11) para as 23h.
Quando o sistema processa vias que são puramente comerciais (comércio fecha às 18h).
Então a cor da via deve transitar de "Verde" para "Amarelo" ou "Vermelho" devido à falta de movimentação e "olhos na rua".

CT-08 — Sobreposição de Filtros
Dado que o mapa está exibindo o índice geral.
Quando a usuária ativa o filtro "Iluminação" (RF-04).
Então o sistema deve destacar em amarelo apenas os segmentos onde o critério de iluminação é o principal redutor do score.

CT-09 — Tratamento de Dados Obsoletos
Dado que uma via teve um relato negativo há 31 dias.
Quando o sistema calcula o score dinâmico hoje.
Então esse relato não deve mais influencia na cor da via (conforme a Janela de Relevância da RN-05), retornando a via ao seu estado base de infraestrutura.

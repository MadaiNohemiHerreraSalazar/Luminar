# UC-14 — Ativar Escolta Digital (Acompanhe-me Virtualmente)

**Produto:** Luminar  
**Objetivo:** Permitir que a usuária compartilhe sua localização exata e o progresso da sua rota em tempo real com contatos de confiança através de um link externo, garantindo monitoramento remoto sem a necessidade de o contato possuir o aplicativo instalado.

## Atores

- **Usuária**
- **Sistema (Backend / Gateway de Comunicação)**
- **Contatos de Confiança (Visualizadores externos)**

## Regras de Negócio Aplicadas

### RN-01 — Independência de Plataforma (Web Viewer)
- O link gerado deve ser acessível via navegadores web (mobile ou desktop) de forma responsiva, utilizando a API do Mapbox para exibir a posição da usuária sobre o mapa base do Luminar.

### RN-02 — Ciclo de Vida do Link (Segurança)
- O link de escolta deve ser único e temporário. Ele deve ser invalidado automaticamente pelo sistema em três cenários:
    1. Quando a usuária clica em "Encerrar Rota/Escolta".
    2. Quando o sistema detecta a chegada ao destino final.
    3. Por *timeout* após 2 horas de inatividade total do GPS.

### RN-03 — Transparência de Dados de Dispositivo
- Para maior segurança da rede de apoio, o link externo deve exibir, além da posição, o nível de carga da bateria do celular da usuária e o status da conexão (Online/Offline).

### RN-04 — Criptografia de Sessão
- A URL gerada deve conter um token de segurança não sequencial para impedir que terceiros acessem localizações de outras usuárias através de tentativas de alteração no endereço web.

---

## Caso de Uso: UC-14

### Pré-condições

- O GPS do dispositivo está ativo e com permissão de "Sempre" ou "Durante o uso".
- A usuária possui conexão de dados estável para o envio das coordenadas ao servidor.

### Gatilho

- A usuária aciona o botão **"Escolta Digital"** ou **"Acompanhe-me Virtualmente"** no painel de navegação ativa.

### Fluxo Principal (Sucesso)

1. O sistema solicita a criação de uma sessão de monitoramento no backend.
2. O servidor gera um link único (ex: `luminar.app/s/a1b2c3d4`).
3. O sistema abre a interface de compartilhamento nativa do smartphone.
4. A usuária seleciona os contatos ou o grupo de confiança (WhatsApp, Telegram, SMS).
5. O sistema inicia o envio de coordenadas em alta frequência (a cada 10-15 segundos) para o servidor.
6. Na interface da usuária, surge um indicador visual (ícone de escudo ou barra roxa) confirmando que a escolta está ativa.
7. O contato de confiança abre o link e visualiza o mapa com o deslocamento em tempo real.
8. Ao chegar ao destino, o sistema encerra a transmissão e exibe uma mensagem de "Trajeto Concluido com Segurança" no link do contato.

### Pós-condições

- A rede de apoio é informada sobre a segurança da usuária durante todo o percurso.
- O link é desativado permanentemente após o uso.

## Cenários de Validação

### CT-01 — Compartilhamento em Rota de Risco
**Dado** que a usuária iniciou uma rota classificada como "Amarela" (atenção) 
 
**Quando** ela ativa a Escolta Digital para seu contato de confiança  

**Então** o contato deve receber o link e visualizar a linha verde da rota planejada e a posição atual da usuária.

### CT-02 — Alerta de Bateria Crítica para o Contato
**Dado** que a escolta está ativa e o celular da usuária atinge 10% de carga  

**Quando** o sistema envia a próxima coordenada  

**Então** a interface do link externo (no navegador do contato) deve exibir um alerta visual: "Atenção: A bateria da usuária está acabando".

### CT-03 — Perda de Sinal durante a Escolta
**Dado** que a usuária entra em uma zona de sombra (sem internet)  

**Quando** o servidor para de receber coordenadas por mais de 60 segundos  

**Então** o link externo deve mostrar a última posição conhecida com o aviso: "Usuária está offline no momento".

### CT-04 — Tentativa de Acesso a Link Expirado
**Dado** que a usuária já encerrou sua rota há 30 minutos  

**Quando** um contato tenta abrir o link de escolta antigo  

**Então** o sistema deve exibir uma página de erro informando: "Este link de monitoramento expirou por questões de segurança".

### CT-05 — Desvio de Rota Notificado
**Dado** que a usuária se afasta significativamente do caminho seguro traçado 

**Quando** a posição GPS é atualizada no servidor  

**Então** o mapa no link do contato deve sinalizar o desvio (ex: mudando a cor da trilha para laranja) para alertar sobre a mudança de trajeto.

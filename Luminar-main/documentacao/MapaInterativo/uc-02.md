# UC-02 — Personalizar Camadas e Filtros Dinâmicos do Mapa

**Produto:** Luminar

**Objetivo:** Permitir que a usuária personalize a visualização do mapa, ativando, combinando ou isolando camadas específicas de segurança e infraestrutura urbana para auxiliar na análise visual do cenário antes e durante seu deslocamento.

## Atores

* **Usuária:** Interage com os seletores de filtros e gerencia a visualização na interface gráfica.
* **Sistema:** API do Luminar e Engine de Processamento Geográfico (Mapbox) que gerenciam a filtragem e a renderização em tempo real.
* **Banco de Dados (PostGIS):** Repositório de dados geográficos que armazena e filtra as coordenadas e atributos dos elementos das camadas.

## Regras de Negócio Aplicadas

### RN-01 — Disponibilidade de Camadas e Multi-seleção

* As camadas disponíveis na interface devem incluir: **Pontos Violeta** (refúgios), **Delegacias/Patrulhamento**, **Iluminação Pública** e **Comércios Abertos**. O sistema deve permitir a ativação de múltiplos filtros simultaneamente, exibindo a interseção dos dados.

### RN-02 — Dinamismo Temporal (Sincronização em Tempo Real)

* A visualização das camadas de "Comércio Aberto" e "Iluminação" deve ser filtrada automaticamente cruzando o horário do dispositivo (ou simulado) com os dados de funcionamento (`opening_hours`) ou relevância noturna.

### RN-03 — Hierarquia Visual (Z-Index) e Esmaecimento

* Os "Pontos Violeta" (ícones roxos) possuem prioridade máxima de sobreposição gráfica (*Z-Index* superior).
* Quando a usuária isolar um filtro específico, o sistema deve reduzir a opacidade das demais camadas em 60% para dar destaque visual absoluto ao critério escolhido.

### RN-04 — Persistência de Filtros

* As camadas selecionadas devem permanecer ativas durante a navegação de uma rota, a menos que a usuária as desative manualmente ou encerre a sessão.

## Caso de Uso: UC-02

### Pré-condições

* O aplicativo possui acesso à internet para carregar os dados geográficos.
* O mapa base interativo está carregado na tela.

### Gatilho

* A usuária aciona o botão de **“Filtros de Estado da Rua”** ou **"Camadas"** na tela principal do mapa.

### Fluxo Principal (Sucesso)

1. O sistema apresenta o menu flutuante com as opções de camadas ativáveis (RN-01).
2. A usuária ativa um ou mais filtros desejados (Ex: "Iluminação" e "Comércios Abertos").
3. O sistema captura o horário atual (RN-02) e faz uma requisição assíncrona ao servidor.
4. O Banco de Dados (PostGIS) filtra os elementos geográficos dentro do quadrante visível (*Bounding Box*) que atendem aos critérios.
5. O sistema renderiza os ícones na tela, aplicando o esmaecimento nas demais camadas (RN-03) e respeitando o *Z-Index* superior dos Pontos Violeta.
6. O sistema exibe um indicador (*badge*) de filtros ativos na tela principal.
7. A usuária visualiza o mapa customizado e pode interatar com os ícones para ver detalhes (como horários de funcionamento).

### Pós-condições

* O mapa exibe visualmente na tela os dados dinâmicos solicitados.
* A visualização customizada é mantida e serve de base caso a usuária decida traçar uma rota inteligente.

## Cenários de Validação 

### CT-01 — Ativar Camada de Pontos Violeta (Prioridade Visual)

**Dado** que o mapa base está visível

**Quando** a usuária ativa a camada "Pontos Violeta"

**Então** o sistema deve renderizar os ícones roxos sobrepostos a qualquer outro marcador (RN-03).

### CT-02 — Filtro de Comércios Pós-Horário Comercial

**Dado** que o horário atual é 22:00h

**Quando** a usuária ativa o filtro "Comércios Abertos"

**Então** o sistema aplica a RN-02 e exibe apenas serviços 24h ou noturnos ativos, removendo lojas fechadas.

### CT-03 — Combinação de Múltiplos Filtros (Interseção)

**Dado** que a usuária quer visualizar apenas ruas iluminadas e movimentadas

**Quando** ela seleciona simultaneamente "Iluminação" e "Comércios Abertos"

**Então** o sistema aplica a RN-01 e destaca apenas os segmentos que atendem a ambos os critérios.

### CT-04 — Limpeza de Filtros e Restauração

**Dado** que o mapa está altamente filtrado

**Quando** a usuária clica em "Limpar Filtros"

**Então** o sistema deve restaurar a opacidade e a visualização padrão do Índice de Segurança Dinâmico em menos de 1 segundo.

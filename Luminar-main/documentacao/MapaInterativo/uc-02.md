# UC-03 — Customizar Camadas de Segurança (Filtros Dinâmicos)

**Produto:** Luminar

**Objetivo:** Permitir que a usuária personalize a visualização do mapa, ativando camadas específicas que exibam elementos de segurança e infraestrutura urbana para auxiliar na tomada de decisão sobre seu trajeto.

## Atores

* **Usuária:** Interage com os seletores de filtros e gerencia a visualização na interface gráfica.
* **Sistema:** API do Luminar e Engine de Processamento Geográfico (Mapbox) que gerenciam a renderização em tempo real.
* **Banco de Dados (PostGIS):** Repositório de dados geográficos que armazena e filtra as coordenadas das camadas.

## Regras de Negócio Aplicadas

### RN-01 — Disponibilidade de Camadas

* As camadas disponíveis para ativação na interface devem incluir obrigatoriamente:
* **Segurança:** Pontos Violeta (refúgio), delegacias e patrulhamento recente.
* **Infraestrutura:** Iluminação pública e comércios abertos.


### RN-02 — Dinamismo Temporal

* A visualização das camadas de "Comércio Aberto" e "Iluminação" deve ser filtrada automaticamente com base no horário local do dispositivo ou no horário simulado pela usuária através do aplicativo.

### RN-03 — Hierarquia Visual (Z-Index)

* Os ícones de "Pontos Violeta" (ícones roxos) devem ter prioridade máxima de sobreposição gráfica (Z-Index superior) sobre qualquer outro marcador de infraestrutura para garantir rápida identificação em caso de emergência.

### RN-04 — Persistência de Filtros

* As camadas selecionadas pela usuária devem permanecer ativas durante a navegação de uma rota (UC-05), a menos que a usuária as desative manualmente ou encerre a sessão do aplicativo.

---

## Caso de Uso: UC-03

### Pré-condições

* O aplicativo possui acesso à internet para carregar os dados geográficos e os tiles do Mapbox.
* O GPS do dispositivo está ativo para centralizar o mapa na posição inicial da usuária.

### Gatilho

* A usuária aciona o botão de **“Filtros de Estado da Rua”** ou **"Camadas"** na tela principal do mapa interativo.

### Fluxo Principal (Sucesso)

1. O sistema apresenta o mapa base renderizado via Mapbox (UC-01).
2. A usuária aciona a ferramenta de filtros/camadas na barra de ferramentas.
3. O sistema exibe o menu com as opções de camadas ativáveis: **Iluminação**, **Comércio Aberto**, **Patrulhamento** e **Pontos Violeta** (RN-01).
4. A usuária seleciona uma ou mais camadas desejadas.
5. O sistema faz uma requisição assíncrona e consulta o banco de dados (PostGIS) para recuperar as coordenadas e status dos elementos das camadas selecionadas dentro do quadrante visível.
6. O sistema renderiza os ícones de referência na tela e estiliza as vias (verde, amarelo, vermelho) conforme o índice de segurança e filtros aplicados.
7. O sistema aplica a hierarquia visual (RN-03), garantindo que os "Pontos Violeta" se sobreponham aos outros marcadores com seus ícones roxos distintos.
8. A usuária visualiza o mapa atualizado e interage livremente com os novos ícones para conferir detalhes.

### Pós-condições

* O mapa exibe visualmente na tela os dados dinâmicos de segurança e infraestrutura solicitados pela usuária.
* A usuária pode iniciar o traçado de uma rota inteligente (UC-05) baseada nessas informações customizadas.

## Cenários de Validação

### CT-01 — Ativar camada de Pontos de Refúgio (Pontos Violeta)

**Dado** que o mapa base está visível na tela

**Quando** a usuária ativa a camada "Pontos Violeta"

**Então** o sistema deve renderizar os ícones roxos com prioridade visual (RN-03) exatamente nos locais como farmácias, cafés e delegacias cadastrados e ativos no banco de dados.

### CT-02 — Alternar visualização por horário (Mapa Dinâmico)

**Dado** uma rua mapeada com comércios locais que encerram as atividades às 20:00h

**Quando** a usuária altera o horário de visualização do aplicativo para as 22:00h

**Então** o sistema deve aplicar a RN-02, remover os ícones de "Comércio Aberto" dessa via e atualizar a cor do seu segmento para Amarelo ou Vermelho devido ao aumento de risco pelo fechamento.

### CT-03 — Visualizar áreas de iluminação precária

**Dado** que existem relatos ativos de "luz quebrada" ou "breu" em uma determinada via

**Quando** a usuária ativa o filtro de "Áreas de Iluminação Precária"

**Então** o sistema deve aplicar um destaque visual diferenciado nas ruas com baixo índice de luminosidade com base nos dados colaborativos.

### CT-04 — Bloquear visualização sem conexão

**Dado** que o smartphone da usuária está completamente sem sinal de internet

**Quando** ela tenta alterar ou ativar uma nova camada de dados

**Então** o sistema deve bloquear a requisição e disparar um aviso informando que a atualização detalhada de camadas não é possível em modo offline.

### CT-05 — Interação com Ponto de Refúgio

**Dado** que um Ponto Violeta está visível e renderizado no mapa

**Quando** a usuária clica diretamente sobre o ícone roxo

**Então** o sistema deve abrir um card flutuante exibindo o nome do local, horário de funcionamento atualizado e o atalho para iniciar a "Navegação de Emergência" (UC-06).

# UC-16 — Realizar Quiz de Conscientização (Onboarding)

**Produto:** Luminar  
**Objetivo:** Educar a usuária sobre as tipificações de violência e assédio no primeiro acesso, garantindo que ela saiba distinguir os tipos de relatos que o app suporta.

## Atores
- **Usuária (Recém-cadastrada)**
- **Sistema (Módulo de Educação)**

## Regras de Negócio Aplicadas
- **RN-01 (Obrigatoriedade Relativa):** Embora seja um requisito *Should* (Desejável), o sistema deve incentivar fortemente o preenchimento no primeiro acesso para "liberar" o selo de usuária colaboradora.
- **RN-02 (Padronização terminológica):** O quiz deve alinhar definições (ex: a diferença entre importunação sexual e assédio) conforme a legislação vigente e os termos usados nos botões de denúncia do app.

### Detalhamento do Caso de Uso Principal

# UC-16 — Realizar Quiz de Conscientização (Onboarding)

## Caso de Uso: UC-16

### Pré-condições
- A usuária realizou o cadastro e está no seu primeiro acesso ao aplicativo.
- O sistema possui o banco de questões e materiais educativos carregados.

### Gatilho
- O sistema identifica o primeiro acesso e exibe a tela de boas-vindas com o convite: **"Vamos aprender a nos proteger juntas?"**.

### Fluxo Principal (Sucesso)
1. O sistema apresenta uma breve introdução sobre a importância de saber identificar situações de risco.
2. O sistema exibe uma série de situações hipotéticas (ex: "Alguém te segue de forma persistente. Como você classificaria isso?").
3. A usuária seleciona uma das opções de resposta.
4. O sistema fornece feedback imediato:
    - Se correto: Reforça a definição técnica.
    - Se incorreto: Explica a diferença entre os termos (ex: Assédio vs. Atitude Suspeita).
5. O sistema percorre as categorias de denúncia disponíveis no app (Luz apagada, Rua deserta, Assédio, etc.).
6. Ao finalizar, o sistema parabeniza a usuária e concede o **Selo de Usuária Consciente**.
7. O sistema libera o acesso ao mapa principal.

### Pós-condições
- A usuária está apta a realizar denúncias com precisão terminológica.
- O perfil da usuária é marcado como "Educado/Consciente" no banco de dados.

## Cenários de Validação

### CT-01 — Conclusão completa com sucesso
**Dado** que a usuária respondeu a todas as 5 questões corretamente  
**Quando** ela finaliza o quiz  
**Então** o sistema deve liberar o selo bronze de "Colaboradora Inicial" e registrar o aproveitamento de 100%.

### CT-02 — Erro em definições críticas
**Dado** que a usuária confunde "Rua Deserta" com "Assédio"  
**Quando** ela seleciona a opção errada  
**Então** o sistema deve exibir um card explicativo curto e pedir que ela tente aquela questão novamente até acertar.

### CT-03 — Opção de "Pular" o Quiz
**Dado** que a usuária está com pressa ou em uma situação que requer uso imediato do mapa  
**Quando** ela clica em "Pular por enquanto"  
**Então** o sistema deve permitir o acesso ao mapa, mas manter um lembrete visual no perfil de que o quiz ainda não foi realizado.

### CT-04 — Atualização de Termos Legais
**Dado** que uma nova lei muda a definição de um crime de gênero  
**Quando** o sistema atualiza o conteúdo do quiz  
**Então** as usuárias antigas devem ser convidadas a fazer uma "Reciclagem de 1 minuto" para manter o selo ativo.

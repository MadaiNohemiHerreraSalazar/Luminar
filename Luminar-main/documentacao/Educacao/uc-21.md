# UC-21 — Validar Nível de Conhecimento (Badge de Colaboradora)

**Produto:** Luminar  
**Objetivo:** Atribuir uma pontuação de credibilidade (Trust Score) ao perfil da usuária com base no seu desempenho no Quiz Conscientizador, definindo o peso inicial de suas futuras contribuições no Índice de Solidariedade.

## Atores

- **Sistema (Módulo de Perfil / Mecanismo de Reputação)**
- **Banco de Dados (Perfil de Usuária)**

## Regras de Negócio Aplicadas

### RN-01 — Cálculo do Fator de Confiança ($F_c$)
- O sistema deve calcular o nível de conhecimento através da fórmula:
  $$F_c = \frac{\text{Acertos}}{\text{Total de Questões}} \times \text{Peso de Conscientização}$$
- Usuárias com $F_c > 0.8$ recebem o status de "Colaboradora Certificada".

### RN-02 — Hierarquia de Badges (Gamificação)
- O sistema deve conceder insígnias (badges) visuais de acordo com o progresso:
    - **Bronze:** Quiz concluído.
    - **Prata:** 10 relatos validados pela comunidade.
    - **Ouro:** Alto índice de precisão em denúncias de infraestrutura.

### RN-03 — Impacto no Algoritmo de Rota
- Os relatos de usuárias com o selo de "Consciente" (UC-20 concluído) devem ser processados pelo sistema com prioridade máxima e peso 1.0, enquanto usuárias sem o quiz possuem peso inicial 0.5 para evitar flutuações baseadas em leiguismo.

### RN-04 — Persistência do Histórico Educativo
- O sistema deve armazenar quais temas a usuária domina (ex: Infraestrutura vs. Segurança Pessoal) para personalizar futuros alertas educativos.

---

## Caso de Uso: UC-21

### Pré-condições

- O **UC-20 (Realizar Quiz)** foi finalizado pela usuária.
- O sistema recebeu o pacote de respostas via API.

### Gatilho

- Finalização do envio dos dados do questionário pelo aplicativo.

### Fluxo Principal (Sucesso)

1. O sistema recebe os resultados do quiz vinculados ao ID da usuária.
2. O sistema contabiliza o número de acertos por categoria (Tipos de Violência, Iluminação, Pontos de Apoio).
3. O sistema atualiza o campo `trust_level` no banco de dados da usuária.
4. O sistema verifica se a usuária atingiu a pontuação mínima para o **Selo de Colaboradora Consciente**.
5. O sistema gera a Badge digital e envia uma notificação push de recompensa: "Parabéns! Você agora é uma Colaboradora Certificada do Luminar".
6. O sistema atualiza os metadatos da usuária para que, a partir deste momento, todos os seus relatos de "Assédio" ou "Rua Deserta" tenham peso total no cálculo dinâmico de rotas (UC-06).
7. O sistema encerra o processo de onboarding educativo.

### Pós-condições

- O perfil da usuária está categorizado por nível de confiança.
- A base de dados ganha uma camada de proteção contra informações imprecisas.

## Cenários de Validação

### CT-01 — Atribuição de Selo com 100% de Acerto
**Dado** que a usuária acertou todas as questões sobre padronização de denúncias  

**Quando** o sistema processa o resultado  

**Então** ela deve receber imediatamente a Badge Ouro de "Especialista em Segurança" e ter seus relatos validados sem moderação prévia.

### CT-02 — Desempenho Insuficiente no Quiz
**Dado** que a usuária acertou menos de 50% das questões  

**Quando** o sistema finaliza o cálculo  

**Então** ele não deve conceder o selo de confiança e deve agendar uma nova sugestão de quiz para daqui a 7 dias.

### CT-03 — Relato vindo de Usuária com Selo
**Dado** que uma usuária com $F_c$ alto reporta "Luz Apagada" em uma via  

**Quando** o sistema recebe o dado  

**Então** o score da via deve cair instantaneamente para "Amarelo", confiando na precisão técnica da usuária.

### CT-04 — Relato vindo de Usuária sem Quiz (Fator de Risco)
**Dado** que uma usuária que pulou o quiz reporta um incidente  

**Quando** o sistema processa a informação  

**Então** ele deve aguardar pelo menos mais 1 relato convergente de outra usuária antes de alterar a cor da rota para todas as demais.

### CT-05 — Expiração de Conhecimento
**Dado** que a legislação de proteção à mulher foi atualizada  

**Quando** o sistema identifica que o quiz da usuária está obsoleto  

**Então** o sistema deve revogar temporariamente o selo de "Certificada" até que o novo módulo seja concluído.
